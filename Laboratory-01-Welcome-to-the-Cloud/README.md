# Laboratory 01 - Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using the KillerCoda Playground. The mission focused on learning basic Linux commands, exploring the system environment, organizing files and directories, and preparing a professional Cloud Computing portfolio using GitHub.

## Objectives

- Access a Linux environment through KillerCoda.
- Navigate and manage the Linux file system.
- Gather basic system information.
- Create and organize files and directories.
- Create a GitHub repository.
- Document technical activities using Markdown.
- Practice version control using Git.

## Activities Performed

1. Accessed an Ubuntu 24.04 environment through KillerCoda.
2. Created and logged into a new Linux user account.
3. Checked the username, working directory, and hostname.
4. Gathered Linux distribution, kernel, CPU, memory, and disk information.
5. Created the required directory structure.
6. Created Markdown documentation files.
7. Created a public GitHub repository for the Cloud Computing portfolio.

## Linux Commands Used

- `whoami` - Displays the current username.
- `pwd` - Displays the current working directory.
- `hostname` - Displays the system hostname.
- `adduser` - Creates a new user.
- `usermod` - Modifies user account settings.
- `su` - Switches to another user account.
- `cat` - Displays the contents of a file.
- `cd` - Changes the current directory.
- `mkdir` - Creates directories.
- `mv` - Moves files or directories.
- `nano` - Creates or edits text files.
- `uname` - Displays system information.
- `lscpu` - Displays CPU information.
- `free` - Displays memory information.
- `df` - Displays disk space information.
- `git` - Manages version-controlled files and repositories.

## Skills Learned

Through this activity, I learned how to work with a Linux terminal, manage users, navigate directories, collect system information, create Markdown documentation, and organize a Cloud Computing portfolio using GitHub and Git.
