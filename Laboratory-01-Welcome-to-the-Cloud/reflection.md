# Reflection

This laboratory activity helped me understand the basic environment used by cloud engineers. I learned how to access an Ubuntu Linux system through KillerCoda and use terminal commands to check system information.

I also learned how to create a Linux user, manage directories, and create Markdown files. Using GitHub helped me understand how technical work can be organized and documented in a professional way.

One of the important things I learned from this activity is that documentation and version control are important in cloud computing. The portfolio will allow me to keep track of my laboratory activities and skills as I continue learning about cloud technologies.
