# Mission 3: Become a Multi-Cloud Explorer

## Mission Overview

This laboratory activity focuses on exploring and comparing three major public cloud platforms: Amazon Web Services (AWS), Microsoft Azure, and Google Cloud Platform (GCP). The activity involves researching their services, infrastructure, strengths, and suitable business use cases.

## Objectives

- Explore AWS, Microsoft Azure, and Google Cloud Platform.
- Identify and compare their core cloud services.
- Analyze different business requirements.
- Recommend appropriate cloud platforms for different scenarios.
- Relate Linux environments to cloud virtual machines.
- Practice professional technical documentation using Markdown.

## Laboratory Files

- `aws-research.md` - Research about Amazon Web Services.
- `azure-research.md` - Research about Microsoft Azure.
- `gcp-research.md` - Research about Google Cloud Platform.
- `cloud-platform-comparison.md` - Comparison of AWS, Azure, and GCP.
- `client-recommendations.md` - Cloud recommendations for different clients.
- `reflection.md` - Personal reflection about the laboratory activity.
